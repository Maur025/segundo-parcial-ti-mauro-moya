# Segundo Parcial - Tecnologias de Internet

Repositorio del segundo parcial de la materia Tecnologias de Internet

**Mauro Eduardo Moya Palli**

## CSS Framework

Se utilizo el framework [tailwindcss](https://tailwindcss.com/) para el diseño de la pagina web.

## Plantilla

Este proyecto utiliza **TailAdmin Angular** (una plantilla gratuita y de código abierto de Tailwind CSS + Angular) licenciada bajo la **MIT License**.  
Fuente: [TailAdmin free dashboard template](https://github.com/TailAdmin/tailadmin-free-tailwind-dashboard-template)

## Accesibilidad

Se han implementado mejoras de accesibilidad en la pagina web, tales como:

- Uso de etiquetas semánticas como `<nav>`, `<header>`, `<main>`, `<footer>`,`<section>`, etc.
- Uso de atributos ARIA para mejorar la navegación y comprensión del contenido.

Los cambios para accesibilidad solo se aplicaron a dashboard y ui-example.
